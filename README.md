# shleeclay.github.io

Seunghyeon Lee (Clay Lee) — Research Portfolio.

Built with Astro + TailwindCSS + DaisyUI. Deployed via GitHub Pages.

**Live:** https://shleeclay.github.io

## Local development

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output: dist/
```

## Content

All site copy lives in `src/data/site.json` with Korean (`ko`) and English (`en`) fields.
Edit JSON only — the components read from there.
